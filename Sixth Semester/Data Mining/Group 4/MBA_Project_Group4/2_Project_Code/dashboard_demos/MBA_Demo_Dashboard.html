Why Segmentation Matters

Every prior study applied one global set of rules to all customers equally. Our project proves this is wrong — High Value customers have 75 unique rules while Low Value customers only show 10 rules. Medium Value customers actually have the strongest lift (10.75) — meaning their co-purchase patterns are the most predictable and actionable. A retailer using our system gives each customer tier a completely different recommendation experience.

S

Support

How often does this combination appear across ALL transactions?

Support(A→B) = freq(A∪B) / N

Example: 100 of 1000 receipts had milk+bread → Support = 0.10

Our threshold: ≥ 0.01 (appears in at least 1% of baskets)

C

Confidence

When someone buys A, how often do they ALSO buy B?

Confidence(A→B) = freq(A∪B) / freq(A)

Example: 100 bought milk+bread, 200 bought milk → Confidence = 50%

Our threshold: ≥ 0.20 (rule correct at least 20% of time)

L

Lift

Is this pattern real or just coincidence?

Lift(A→B) = Confidence / P(B)

Lift = 1 → coincidence. Lift > 1 → real pattern. Lift > 3 → strong. Lift > 10 → exceptional.

Our Avg Lift = 10.57 — Exceptional
K

Conviction

How much does rule A→B depend on each other? Filters out accidental rules.

Conviction = (1 - P(B)) / (1 - Confidence)

Conviction > 1 means the rule is not random. We used ≥ 1.1 to prune weak rules — this directly addresses Gap 2.

R

RFM Segmentation

Score every customer on 3 dimensions:

R = Recency (days since last buy)
F = Frequency (how many orders)
M = Monetary (total spend)

Each scored 1–3, summed to 3–9. Score ≥ 8 = High Value, ≥ 5 = Medium, else Low.

A

Apriori Algorithm

Works in passes over the data:

Pass 1: Find frequent single items
Pass 2: Build frequent pairs
Pass 3: Build frequent triplets

Uses "anti-monotone" property — if {A,B} is infrequent, no superset {A,B,C} can be frequent. Prunes search space massively.

Gap Resolution Proof
Gap 1 — Scalability
Prior studies never measured how fast Apriori runs or how it scales with data size. We measured execution time for each segment separately.
Full: 13.64s · High: 3.83s · Medium: 0.62s · Low: 0.08s
Gap 2 — Weak Rule Pruning
Standard studies only filter by Support and Confidence. We added Conviction ≥ 1.1 as a third filter, removing accidental/redundant rules.
461 rules survived pruning from 444 frequent itemsets
Gap 3 — No Customer Segmentation (Core Novelty)
No prior student-level study runs Apriori separately per RFM segment. We proved High Value customers have 75 rules, Medium 29, Low only 10 — proving segments behave differently.
High: 75 rules · Medium: 29 rules · Low: 10 rules
Gap 4 — Temporal Patterns
Prior studies use static data with no time analysis. We extracted monthly revenue trends, day-of-week patterns, and hourly transaction distributions from InvoiceDate.
